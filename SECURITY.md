# Security

Report a vulnerability privately, through GitHub: on the repository's [Security tab](https://github.com/bimsonz/mfp/security), choose **Report a vulnerability**. Never report one in a public issue. Say what is affected (the schemas, `@bimsonz/mfp/emit`, the profile check, or the specification's normative text), and how to reproduce it.

The maintainers fix a confirmed problem before it is disclosed, and credit the report unless you ask otherwise.

What an MFP message may and may not be trusted for is specified in [Security considerations](docs/specification/0.2/security.md). A receiver that takes standing from a message's content breaks that specification; it is not a vulnerability in MFP.
